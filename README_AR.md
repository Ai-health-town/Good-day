# G’day Workspace — Neon Storage + AI

تطبيق Python وStreamlit بهوية جديدة: قائمة جانبية بلون البرقوق الداكن، أزرار تركواز، ومساحة عمل فاتحة. يحتفظ بهيكل تخزين وحسابات النسخة السابقة التي جهزناها في هذه المحادثة، ولا يحتاج قاعدة جديدة عند تحديثها.

هذه النسخة تضيف **تخزين ملفات منفصلًا في Neon** و**مساعدًا فعليًا عبر Neon AI Gateway**، مع محادثات محفوظة لكل حساب ومراجعة التغييرات قبل تطبيقها. ابدأ من [NEON_SETUP_AR.md](NEON_SETUP_AR.md) لتفعيل خدمات حسابك. يبقى التطبيق قابلًا للعمل بدون الإضافتين حتى تكمل إعدادهما.

## تحديث منصتك الحالية

1. من منصتك الحالية افتح **حفظ اليوم** ونزّل نسخة رجوع.
2. فك ضغط الحزمة وارفع **كل محتوياتها معًا** إلى جذر مستودع GitHub الحالي، واستبدل الملفات القديمة المطابقة. لا ترفع ملف ZIP نفسه بوصفه كود التطبيق.
3. أبقِ **Main file path = `app.py`** وأبقِ **Secrets الحالية كما هي**، خصوصًا `DATABASE_URL`. لا تحتاج مشروع Neon أو حسابات جديدة.
4. انتظر إعادة تثبيت المتطلبات لتظهر الواجهة الجديدة مع البيانات الموجودة في القاعدة نفسها.

ارفع جميع الملفات معًا، بما فيها `cloud_storage.py` و`ai_service.py` و`ai_store.py` و`ai_ui.py`، بجانب ملفات التطبيق السابقة و`requirements.txt`. ارفع كذلك مجلد `.streamlit` الذي يحتوي إعدادات الألوان؛ قد يكون مخفيًا في جهازك. أداة `manage.py` لاستعادة حساب المدير، ومجلد `tests` للاختبارات.

التشغيل لا يعيد تهيئة حساب موجود ولا يستبدل محتوى العمل. كل استيراد أو استعادة يبدأ من إجراء تختاره داخل المنصة. لا تحذف قاعدة البيانات أو تغيّر رابطها أثناء التحديث.

## مساحات العمل

| المساحة | ما تقدمه |
|---|---|
| نظرة اليوم | الأولويات، تقدم المشاريع، آخر الملفات، وتكملة العمل من آخر تسليم |
| المهام | إضافة سريعة، جدول قابل لتحرير المسؤول والحالة والأولوية والتاريخ والمدة، ولوحة إنجاز بإجراءات مباشرة |
| المشاريع | اختيار مشروع من القائمة الجانبية لتصفية المهام والملفات والتقارير |
| الملفات | بحث وتصنيف ومفضلة، رفع جماعي، ومنع حفظ الملف المطابق مرة أخرى |
| المستندات | تحرير النص وتصدير Word، مع تنزيل الأصل كما رُفع |
| الجداول | قراءة أوراق Excel الحقيقية، تعديل الصفوف وإضافة عمود، وتصدير Excel |
| PDF | معاينة داخل المنصة، مع الأصل والملاحظات المرتبطة به |
| الدردشات | قنوات ومرفقات وتحويل رسالة إلى مهمة والتحكم بالحذف حسب الدور |
| البحث الشامل | العثور على مهمة أو ملف أو جهة وفتح تفاصيلها من مكان واحد |
| مركز المساعد | محادثة AI محفوظة لحسابك، قراءة مقتطفات الملفات المختارة، واقتراح مهام ومستندات وتسليم للمراجعة؛ وتبويب مستقل لمساعد المتصفح |
| التقارير | ملخص تنفيذي بلا أسماء أفراد، قابل للتحرير والتنزيل Word، مع Excel وتوزيع العمل بالساعات |
| الربط والتخزين | للمدير: حالة الاتصالات، فحص الوصول للمخزن والبوابة، ونقل أصول الملفات الموجودة |

الملخص الأساسي في صفحة التقارير وترتيب الأولويات محسوبان محليًا. عند إرسال سؤال من **مساعد AI داخل المنصة**، تمر مقتطفات الملفات المختارة والسياق الذي تسمح به عبر Neon AI Gateway إلى نموذج الاستدلال. لا تُرسل مفاتيح الاتصال أو كلمات المرور أو دردشات الفريق أو الملفات غير المختارة. تُحفظ المحادثة في جداول مستقلة لحساب المستخدم.

حساب مساعد المتصفح يستخدمه مساعد عندما تكلفه بفتح المنصة. النموذج المدمج يعمل عند إرسال سؤال؛ لا يشغّل أي منهما عاملًا يعمل في الخلفية تلقائيًا. الحسابات الحالية تبقى كما هي، ولا تحتاج إعطاء مساعد المتصفح بيانات دخول Neon أو رابط اتصال القاعدة الخاص.

## بداية اليوم: الدمج أو الاستعادة

**إضافة ودمج دون استبدال:** ارفع ملف JSON واختر المشروع الذي يستقبل المحتوى غير المطابق. راجع المعاينة ثم أضف المحتوى الجديد. يضيف النظام المهام والجهات والملفات، ويترك الموجود دون تغيير. يطابق المسؤول عندما تكون المطابقة واضحة، وإلا يحفظ اسمه الأصلي في الملاحظات ويترك الإسناد فارغًا. المحادثات القديمة تحفظ في مستند أرشيفي بدل نشرها كرسائل جديدة بأسماء أصحابها.

يستطيع الدمج العضو أو المساعد الذي مُنح صلاحية التعديل. لا ينشئ الدمج حسابات أو مشاريع أو صلاحيات جديدة. يشمل التوافق النسخة الأصلية `gday_rcm_backup_YYYY-MM-DD.json` ونسخ المنصة الحالية بإصدار 2 وتنسيق المرجع الذي يستخدم `doing / waiting` و`estHours / grid / chats`.

**استعادة النسخة كاملة:** للمدير والمشرف فقط. تستبدل حالة العمل بمحتوى الملف بعد التأكيد، مع حفظ نقطة رجوع تلقائية والإبقاء على حسابات الدخول الحالية. استخدم الدمج أو رفع الملفات إذا كنت تريد الإضافة فقط.

## التعديلات والحفظ

عدّل خلايا الجدول ثم اضغط **حفظ تعديلات الجدول**. تحفظ الدفعة كاملة؛ إذا تغير صف لدى زميل منذ فتحه، يرفض النظام الدفعة ويطلب تحديث العرض قبل الكتابة فوق بيانات جديدة. من **تحديث الجدول** تحمل آخر نسخة.

من لوحة الإنجاز يمكن بدء المهمة وإنهاؤها واستئنافها وإعادة فتحها. يسجل النظام وقت الإكمال عند تغيير الحالة إلى مكتملة، ولا يخترع وقتًا للمهام التاريخية المستوردة.

كل تغيير تضغط حفظه يكتب في القاعدة. من **حفظ اليوم** نزّل JSON يشمل حالة العمل وتسليم اليوم، دون كلمات المرور أو الجلسات. المرفقات الموجودة في القاعدة مضمنة، وأصول Object Storage ممثلة بروابط خاصة تحتاج المخزن نفسه. من **إعداد نسخة تشمل الملفات الأصلية** جهّز نسخة مستقلة بالأصول حتى 30 ميجابايت. يستطيع المدير والمشرف حفظ وتنزيل آخر 14 نقطة رجوع. حذف محادثة حالية لا يغير نسخة سبق تنزيلها.

محادثات AI الخاصة ليست ضمن النسخة المشتركة. يمكن لكل مستخدم تصدير محادثته أو حذفها من مركز المساعد. التطبيق يفصل الوصول بين الحسابات؛ هذا ليس تشفيرًا يمنع مالك قاعدة البيانات من الوصول الإداري إليها.

عند تفعيل Object Storage تحفظ الرفعات الجديدة أصولها فيه، وتبقى النصوص والجداول المحررة في القاعدة. لنقل الملفات الموجودة افتح **الربط والتخزين → نقل الملفات الحالية**. العملية تحفظ نقطة رجوع ولا تغير معرفات الملفات أو المهام المرتبطة بها. إذا فشل رفع أحد الأصول لا تُعتمد دفعة نقل جزئية. قد يبقى أصل غير مرتبط في المخزن إذا فشلت معاملة القاعدة بعد الرفع؛ المفاتيح ببصمة المحتوى تمنع تكرار نسخة ثانية من الأصل نفسه عند الإعادة.

حذف سجل ملف من المكتبة لا يحذف الأصل من Object Storage، لأن النسخ السابقة قد تشير إليه. لا توجد أداة تنظيف تلقائي للأصول في هذه النسخة؛ لا تحذف المخزن أو تغيره إذا كنت تحتاج نقاط الرجوع القديمة.

## كيف يعمل مساعد AI

1. افتح مركز المساعد واختر مشروعًا ومحادثة محفوظة أو محادثة جديدة.
2. اختر حتى خمسة ملفات، وحدد إن كنت تريد إرسال مهام المشروع والتسليم المشترك وأسماء الفريق.
3. أرسل سؤالك. يرى النموذج مقتطفات ببحث كلمات من الملفات المختارة وسياقًا محدودًا، وليس كل مكتبتك. تُقرأ حتى 30 صفحة من PDF النصي؛ لا يوجد OCR للملفات المصورة.
4. إذا طلبت تغيير العمل، يظهر مقترح لمهام أو مستند نصي أو تسليم اليوم. راجع القيم ثم اضغط **تطبيق وحفظ**.

المقترح لا يكتب في العمل قبل المراجعة، ولا يمكنه حذف بيانات أو إنشاء حسابات أو تغيير أدوار أو تشغيل SQL أو إرسال رسائل للفريق. يعيد الخادم التحقق من جلسة المستخدم وصلاحياته وإصدارات السجلات عند التطبيق. لو تغيّرت مهمة أو التسليم منذ قراءة المساعد، تُرفض الدفعة كاملة. تطبيق المقترح مرتين لا يكرر التغييرات، وتؤخذ نقطة رجوع قبل التطبيق.

الافتراضي 40 طلبًا يوميًا لكل حساب بتوقيت الرياض، وحتى 1800 وحدة إخراج لكل طلب، ويمكن تعديلهما من Secrets. الطلب الفاشل يحتسب لأن الخدمة ربما استقبلته؛ حذف المحادثة لا يعيد ضبط الحد. ليست هذه حدود تكلفة مالية؛ راقب الرصيد والفوترة في Neon. لا تعاد الطلبات المدفوعة تلقائيًا عند فشل الشبكة.

لكل حساب حتى 100 محادثة، وحتى 200 رسالة في المحادثة. تُحفظ المحادثات والتغييرات عبر إعادة التشغيل عند استخدام PostgreSQL. راجع النتائج قبل استخدامها؛ محتوى النموذج قد يكون ناقصًا أو غير صحيح.

## تشغيل جديد من الصفر

ارفع الملفات إلى GitHub، وأنشئ تطبيقًا في [Streamlit Community Cloud](https://share.streamlit.io) باستخدام `app.py` وPython **3.12**. جهّز PostgreSQL، وانسخ رابط الاتصال من مزود القاعدة. من Streamlit → Settings → Secrets أضف:

```toml
DATABASE_URL = "postgresql://USER:PASSWORD@HOST:5432/DATABASE?sslmode=require"
GDAY_ADMIN_USERNAME = "your_admin_name"
GDAY_ADMIN_PASSWORD = "REPLACE_WITH_YOUR_PRIVATE_PASSWORD_12_PLUS"
GDAY_ADMIN_NAME = "مدير المنصة"
REMEMBER_DAYS = 90
GDAY_LOCAL_MODE = false
```

استبدل الرابط وكلمة المرور بقيمك. لا ينشأ الحساب بقيمة تبدأ بـ `REPLACE`. ينشأ المدير الأول مرة واحدة؛ تغيير كلمة مروره في Secrets لاحقًا لا يغير حسابًا موجودًا. لا ترفع `.streamlit/secrets.toml` الحقيقي أو قاعدة البيانات أو نسخ العمل إلى GitHub.

للتجربة المحلية، ثبّت المتطلبات داخل بيئة Python، وضع `GDAY_LOCAL_MODE = true` وبيانات المدير في `.streamlit/secrets.toml` المحلي، واترك `DATABASE_URL` غير معرف. ثم:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

في التجربة تنشأ SQLite في `data/gday.db`. استخدم PostgreSQL للحفظ الدائم في الاستضافة. لاستعادة كلمة مرور المدير من جهاز يملك اتصال القاعدة الخاص:

```bash
python manage.py reset-admin your_admin_name
```

## الحدود والتحقق

8 ميجابايت لكل مرفق، و30 ميجابايت لحالة العمل النصية ونسخة الاستيراد، و20 ورقة / 5000 صف / 60 عمودًا لكل Excel. Object Storage يفصل حجم الأصول عن حالة العمل؛ النصوص المحررة والجداول تبقى ضمن حد 30 ميجابايت. جداول الحسابات ومحادثات AI مستقلة عن هذا الحد، وتستهلك حصة التخزين في حساب Neon.

تحرير Word نصي والتصدير ينتج مستندًا مبسطًا، مع حفظ الأصل بتنسيقه. Excel المحرر يصدر القيم كنصوص ولا ينفذ المعادلات أو الماكرو. أي أصل لم تحفظه نسخة HTML القديمة لا يمكن إعادة بنائه من النص وحده.

تحسّن القراءة باستخدام رقم مراجعة صغير وإعادة استخدام المحتوى غير المتغير، مع فحص الجلسة في كل قراءة. تستمر حماية السجلات المتزامنة ونقاط الرجوع.

```bash
python -m pip install pytest
python -m pytest -q
```

تغطي الاختبارات الدخول والصلاحيات والجلسات والملفات والنسخ والدمج المتكرر وعدم استيراد صلاحيات، وتعديل الجدول والتعارض وذاكرة القراءة ونماذج Streamlit، إضافة إلى التخزين المنفصل وسلامة الأصول وخصوصية محادثات AI وحدود الاستخدام ومراجعة المقترحات وتطبيقها مرة واحدة. اختبارات الخدمات تستخدم اتصالات اختبار محلية ولا تثبت تفعيل حساب Neon الحقيقي. اتصال مشروعك والنموذج والمنطقة والرصيد تُفحص بعد ربط حسابك؛ لا توجد بياناتك الخاصة في الحزمة.
